# Monitor do PC 🖥️

Monitor simples do computador feito em Python.

## Funcionalidades

* Monitoramento da CPU
* Monitoramento da memória
* Monitoramento do disco
* Monitoramento da rede
* Interface gráfica
* Fundo com degradê e GIF

## Instalação

```bash
pip install psutil pillow
```

## Como usar

```bash
python main.py
```

## Tecnologias

* Python
* Tkinter
* Psutil
* Pillow
